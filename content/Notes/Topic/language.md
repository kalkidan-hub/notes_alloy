> [!note]
> A language is a **structured system of communication** that uses symbols, words, gestures, or signs governed by specific operational rules (**syntax**) to encode and transfer information (**semantics**).

- **Primary Purpose:** To bridge the gap between internal thought, state, or intent and an external agent—whether that agent is another human, an abstract mathematical engine[model], a software compiler, or a physical machine.
### Taxonomy of Language Types
#### Natural
- Human languages that evolved organically through social interaction and culture.
- Example: English, Spanish
- Context-dependent, highly expressive, inherently ambiguous, dynamic vocabulary.
#### Modeling
- Structural or behavioral blueprints that represent abstract systems without execution mechanics.
- Example: UML, [[Alloy]], ERD
- High abstraction level, graphical/textual specifications, relationship-centric.
#### Formal / Mathematical 
- Rigorous symbolic systems designed to state axioms, construct proofs, and evaluate truth values.
- Example: First-Order Logic, Set Theory, $\lambda$-calculus
- Zero ambiguity, axiomatic, strict deductive mechanics, mathematical sound/complete guarantees.
#### Markup & Serialization 
- Declarative notations designed to annotate document structures or format data for transfer.
- Example: HTML, JSON, YAML, XML
- Static structure description, non-executable, human and machine-readable data layouts.
#### Programming 
- Execution-oriented instructions designed to control machine operations and memory states.
- Example: Python, Java, JavaScript
- Imperative or functional logic, deterministic execution, explicit control flow.

#### Query
- Declarative systems built specifically to extract and manipulate data within structured stores.
- Example: SQL, Cypher, GraphQL
- Focuses on _what_ data to retrieve rather than _how_ to compute it, relational logic.
#### Hardware Description(HDL)
- Systems created to model concurrent digital logic, signal timings, and physical circuit gates.
- Example: VHDL, Verilog
- Models massive concurrency/parallelism, register-transfer level (RTL) focus.
#### Constructed(Conlang)
- Human-to-human communication systems intentionally engineered rather than organically evolved.
- Example: Esperanto
- Can range from artistic/fictional world-building to logically strict auxiliary systems.
