These types of languages are involved in development of a working website
	- Natural Language: for communication with client and among teams
	- Modeling: to layout the use-case diagrams and also for database entity relation diagram
	- Markup & Serialization: to draw the page[HTML], to transfer data[JSON], to set configuration rules [YAML]
	- Query: to perform queries on the database
	- Programming: to write the logic of the system 


[ Client Requirement ]
       │  (Natural Language)
       ▼
[ Architectural Blueprint ]
       │  (Modeling Language: ERD / Use Case)
       ▼
[ Business & Server Logic ]
       │  (Programming Language: Python / TypeScript)
       ▼
[ Data Fetch & Persist ]
       │  (Query Language: SQL)
       ▼
[ Data Transfer & Configuration ]
       │  (Serialization & Markup: JSON / YAML)
       ▼
[ UI Display ]
       │  (Markup Language: HTML)
